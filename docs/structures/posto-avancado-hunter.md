# Posto Avançado da Associação Hunter

Contrato inicial do marco ST1. O layout de referência ocupa `37x37` blocos,
com paliçada de quatro blocos, prédio principal de até nove blocos e torre de
dezesseis blocos. Os seis módulos são `portao`, `patio`, `predio_principal`,
`torre`, `pesquisa` e `deposito`.

Este arquivo congela apenas a geometria do blockout. O template `.nbt`, o
placement natural, loot e decoração entram em issues posteriores do marco.
Enquanto o template não existir, nenhum worldgen do posto é registrado.
